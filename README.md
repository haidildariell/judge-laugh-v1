Entry for the make.fun bounty "Make the AI Judge Laugh": a program that writes
one single-line joke about office life (under 200 characters) to
`/output/entry.txt`. The joke is about a daily standup that drags on so long
the newly hired intern already hands in his resignation from the chair next
to the narrator.

Bounty: https://make.fun/bounty/u-rama-melon-make-the-ai-judge-laugh-302d0825

## Run

```sh
python3 main.py
cat /output/entry.txt
```
